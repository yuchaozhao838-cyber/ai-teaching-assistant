# AI 课堂助手 · 使用说明

> 适用版本：v1.0.0（Windows 10 / 11，x64）
> 一句话：把课件丢进来，得到「逐节讲解 + 三档重点」，还能导出成 Word / PPT / PDF 复习。

---

## ⚠ 零、先看这条：不要放在桌面/文档/图片/下载目录里运行

本机（以及很多装了火绒/360/联想电脑管家等安全软件的机器）的「桌面、文档、图片、下载」目录
被**防勒索保护**加了拒绝删除权限（ACL 里有一条 `Everyone: 拒绝 DeleteSubdirectoriesAndFiles`）。
Electron 程序从这些目录启动时会在初始化阶段直接以 **0x80000003** 崩溃 ——
表现就是"双击加载一会儿，但没有任何窗口"，而且日志、崩溃记录都不产生。

**解决办法（任选其一）：**

1. 把程序解压/安装到 **`C:\AI-Tutor-Assistant`** 这类非受保护目录（推荐，已实测可用）；
2. 在安全软件的「防勒索 / 文档保护 / 文件夹保护」里，把程序所在目录加入白名单。

> 实测：同一份程序放 `C:\` 下窗口正常出现、界面正常加载；放桌面就 0x80000003。
> 连电脑上原本正常的 DeepSeek Harness，复制到桌面后也起不来 —— 所以这不是程序本身的问题。

## 一、安装

**方式 A：解压即用（推荐，最稳）**

下载 `AI-Tutor-Assistant-1.0.0-win64.zip` → 解压到一个文件夹（别只把 exe 拖出来，它要同目录的 dll 和 resources）→ 双击 `AI-Tutor-Assistant.exe`。

**方式 B：免安装单文件**

双击 `AI-Tutor-Assistant-1.0.0-portable.exe`。它本质是"自解压 + 启动"，少数安全软件（如火绒/360 的主动防御）会拦截这个自解压层，表现为"转圈一会儿但没有任何窗口"。遇到这种情况请改用方式 A。

**方式 C：安装版**

双击 `AI-Tutor-Assistant-1.0.0-setup.exe` → 选择安装目录 → 完成后桌面出现「AI课堂助手」。

> 应用未做代码签名，Windows 可能提示「Windows 已保护你的电脑」。
> 点 **更多信息 → 仍要运行** 即可（文件来自你自己的电脑，可以放心）。

### 双击后没有窗口？按这个顺序排查

1. **先换方式 A（ZIP）** —— 能绕开安装器/自解压层被安全软件打断的问题；
2. **给安全软件加信任** —— 火绒 / 360 / 腾讯电脑管家：把解压出来的整个文件夹加入「信任区」，或临时退出后重试；
3. **跑一遍「兼容模式启动.bat」** —— 关闭 GPU 加速再启动一次；
4. **跑「诊断.bat」** —— 会在同目录生成 `诊断日志.txt`，里面记录了 Electron 是否启动、程序执行到哪一步，把这个文件发我即可定位。

启动日志也可以手动查看：

| 文件 | 含义 |
| --- | --- |
| `%APPDATA%\AITutorAssistant\boot.log` | 程序代码是否被加载（没有它=Electron 本体没起来） |
| `%APPDATA%\AITutorAssistant\startup.log` | 启动到哪一步（窗口创建 / 界面加载成功与否） |

## 二、第一次使用：配置模型

打开应用 → 左下角 **设置**。

1. 在「模型供应商」里选中一个，或点 **添加**；
2. 用「快速填充（预设）」选供应商，会自动填好 Base URL 和模型名：

| 供应商 | Base URL | 模型名 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问（百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 华为云 MaaS | 以控制台给出的 OpenAI 兼容地址为准 | 以控制台为准 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

3. 填入 **API Key**（在对应平台的「API Key 管理」页面创建）；
4. 点 **测试连接**：出现「连接成功（xxx ms）」说明可用；
5. 点 **保存配置**（保存后会自动设为「使用中」）。

> 不想折腾密钥？保持默认的「**本地演示模型**」也能走完整个流程：它不联网，用材料里的标题和原文规则化生成讲解（内容仅供体验，不代表 AI 讲解质量）。

**关于温度**：0.6 比较均衡；想要更稳定贴原文可调到 0.3；想要更多例子可调到 0.9。

## 三、导入学习材料

在 **资料库** 页有三种方式：

1. **导入文件**：支持 PDF（有文本层的）、Word（.docx）、PPT（.pptx）、Markdown、TXT、CSV、JSON、HTML；可多选。
2. **网页抓取**：两种模式
   - **公开页面（直接抓）**：粘贴网址，程序用隐藏浏览器打开并提取正文，自动去掉广告与导航；
   - **需要登录 / 要翻页（打开浏览窗口）**：点「① 打开 / 刷新抓取窗口」会弹出一个**真实浏览器窗口**，你在里面登录、翻页、点「显示更多」，内容加载好后回到主窗口点「② 抓取当前页面」即可导入。登录状态保存在本机（独立分区），下次抓同一网站不用重新登录；抓完一页可以继续翻页再抓。
   - **抓附件**：抓完页面后，如果这一页挂着 PDF / PPT / Word / ZIP 等附件，会自动弹窗列出来，勾选后「下载并导入」——用抓取窗口的登录态下载，课件和答案一并变成学习材料。
3. **粘贴文本**：直接粘贴课本段落、老师发的题目、自己整理的笔记。支持 `#` 标题、`-` 列表、`$公式$` 等 Markdown 写法。

导入后可点材料行打开 **预览**，确认解析对不对：

- 标题层级是否保留；
- 有没有出现「解析提示」；
- 分段是否合理。

### 关于 PDF 的公式与图表

两条路：

**A. 普通导入（快，够用）**：只取文字层。公式的上下标、分式、根号会被拉平成一行纯文本；纯图片/扫描页没有文字。导入后程序会**按页码提示**：

- `第 3、5 页公式较多…` → 这几页建议用「粘贴文本」贴原文，或对照原 PDF 检查 AI 写的公式；
- `第 7 页没有文字层（扫描页 / 纯图片）…` → 这页 AI 看不到，可截图后把要点粘进来。

**B. 识图导入（慢一些，公式保真）**：资料库 → **「PDF 识图导入（公式更准）」**。

程序会把 PDF 每一页**渲染成图片**，交给**视觉模型**逐页转写成 Markdown + LaTeX，公式的上下标、分式、根号、积分限都能保留下来，连图表描述也会带上。

- 需要**支持图片输入**的模型：通义 `qwen-vl-max`、OpenAI `gpt-4o-mini`、智谱 `glm-4v` 等；DeepSeek 文本模型不支持；
- 在「设置」里把模型换成视觉模型，测试连接通过后保存即可；
- 每次最多识别 12 页（够一次课件量），逐页识别时界面会显示进度；
- 识别结果会存成一份「xxx（识图转写）」材料，之后照常「生成讲解」。

## 四、生成讲解

在材料行点 **生成讲解**（已有讲解的显示「重新生成」）。

生成过程分三步，进度条会显示当前阶段：

1. **分块提炼**（长文档才有）：把材料切块，逐块提炼核心要点；
2. **生成大纲**：拆出 5–8 个按认知顺序排列的知识点；
3. **逐节讲解 + 划重点**：每节流式生成，右侧同步出现重点条目。

生成期间可以点右上角 **取消**：已完成的小节会保留，状态标记为「部分完成」。

用了本地演示模型时，一次生成约 3 秒；真实模型按材料长度，通常 1–3 分钟。

## 五、阅读与编辑

讲解页分三栏：

- **左：讲解大纲** —— 点标题跳转到对应小节；标题右侧的小数字是该节的要点条数；
- **中：讲解正文** —— 每节包含「一句话结论 → 为什么 → 例子 → ⚠ 易错点」，公式用 KaTeX 排版；
- **右：重点划分** —— 分 **必须掌握 / 理解即可 / 了解即可**，可点标签筛选，每条都注明「属于哪一节 · 为什么重要」。

想改内容：

- 单节右上 **编辑** → 修改 Markdown → 保存（会被标记「已编辑」，不会被覆盖）；
- 单节 **重生成** → 只重跑这一节（流式覆盖，可再次取消）；
- 顶部 **重新生成** → 重跑整篇（会新建一份讲解记录）。

## 六、习题练习（可选，不强制）

左侧导航 **练习**。设计上**不要求你做任何题**：题目和解析是给你看的资料，答案默认收起，想看再点开。

三种来源：

1. **从材料出题** —— 选一份已导入的课件/网页材料，AI 按知识点出题，附答案 + 3-6 步解析；
2. **整理已有题目** —— 把老师发的卷子（PDF/Word/网页抓取的材料）里的题目整理成结构化题目，缺答案的自动解出来补解析；
3. **自己出题** —— 「空白题集」→「添加一题」，手写题干、选项、答案、解析（支持 Markdown 和 `$公式$`）。

生成时可选题量（1-20）、难度（混合/基础/中等/进阶）、题型（选择/填空/计算/证明/简答）。

阅读方式：

- 每题一张卡片，题干和选项里的公式会排版显示；
- **看答案与解析** 单个展开，顶部 **全部展开答案 / 全部收起** 一键切换；
- **编辑** 改题干/答案/解析，**删除** 去掉某题，**删除题集** 清掉整份；
- 生成结果自动存在本地，下次打开还在。

> 出题需要真实模型（DeepSeek / 通义千问等），本地演示模型只能体验讲解流程。

## 七、导出

右上角 **导出** → 选择格式：

| 格式 | 适合 | 说明 |
| --- | --- | --- |
| **Word（.docx）** | 打印、改笔记 | 封面 + 大纲 + 逐节详解 + 重点表格；公式为线性文本（如 `f'(x₀)=lim(Δx→0)…`） |
| **PowerPoint（.pptx）** | 课上汇报 | 封面 + 大纲 + 最多 6 个知识点页（每条精简为要点）+ 重点页 + 复习建议 |
| **PDF（.pdf）** | 手机看、发群里 | A4 排版，公式用 KaTeX 渲染，最接近屏幕效果 |
| **Markdown（.md）** | 放进 Obsidian/Notion | 保留 `$公式$` 原文，方便二次编辑 |

> Word / PPT 里没有公式排版引擎，所以公式会转成可读的线性写法；要「漂亮的公式」请导出 PDF。

## 八、数据与隐私

| 内容 | 位置 |
| --- | --- |
| 材料、讲解、设置 | `%APPDATA%\AITutorAssistant\data\` |
| API Key（DPAPI 加密） | `%APPDATA%\AITutorAssistant\secrets.json` |

- 所有材料只存在本机，**不上传任何服务器**；
- 只有点击「生成讲解」时，才会把与当前小节相关的材料片段发送给你配置的模型服务；
- API Key 用 Windows DPAPI 加密，只有当前 Windows 用户能解密，界面不回显；
- 想清空数据：设置页 → **打开目录** → 删除 `data` 文件夹里的文件（或整个 `AITutorAssistant` 目录）。

## 九、常见问题

**Q1：提示「API Key 无效或已过期」（HTTP 401）**
Key 复制不全 / 已删除 / 额度用完。到设置页重新粘贴并点「测试连接」。

**Q2：提示「HTTP 404，接口地址或模型名可能不对」**
Base URL 少了 `/v1`，或模型名拼错。参考第二节的表格。

**Q3：提示「无法连接到模型服务」**
检查网络、代理或公司防火墙；OpenAI 需要能访问 `api.openai.com` 的网络环境。也可以换 DeepSeek / 通义。

**Q4：PDF 导入后没有内容 / 内容是乱码**
大概率是扫描件（没有文本层）或加密 PDF。请改为「粘贴文本」。

**Q5：生成到一半失败**
已完成的小节会保留。点「重生成」重试失败的小节即可；若整体失败，检查模型额度或换模型再试。

**Q6：Word 里公式是乱的反斜杠**
说明这一节公式较多。请导出 PDF，或在 Word 里手动替换（`\frac{a}{b}` 已转成 `a/b` 这类可读形式）。

**Q7：双击没反应 / 启动很慢**
免安装版首次启动需要自解压，请等 10 秒左右；若被 SmartScreen 拦截，见第一节说明。

**Q8：能离线用吗？**
应用本身可离线安装运行；生成讲解需要联网（除了「本地演示模型」）。
