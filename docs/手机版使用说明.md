# AI 课堂助手 · 手机版（PWA）

这是把桌面版界面搬到浏览器的版本，**不是 APK**，但可以「添加到主屏幕」，点开就是全屏 App 的样子。

## 怎么在手机上打开

1. 电脑上双击 **`启动手机版.bat`**（会开一个小黑窗口，别关它）；
2. 窗口里会打印两行地址：
   - `http://127.0.0.1:8899/` —— 电脑自己看
   - `http://192.168.x.x:8899/` 或 `http://10.x.x.x:8899/` —— **手机用这个**
3. 手机连**同一个 Wi-Fi**，把地址输进浏览器（Chrome / Edge / 夸克都行）；
4. 打开后点浏览器菜单里的 **「添加到主屏幕」**，以后从桌面图标点开即可。

> 打不开时：多半是 Windows 防火墙拦了 8899 端口。用管理员身份打开 PowerShell 执行一次：
> ```
> New-NetFirewallRule -DisplayName "AI 课堂助手手机版" -Direction Inbound -Protocol TCP -LocalPort 8899 -Action Allow
> ```
> 或者把电脑开热点、手机连电脑的热点，再用窗口里显示的地址。

## 手机版能做什么

| 功能 | 手机版 |
|---|---|
| 导入 PDF / Word / TXT / Markdown / HTML | ✅（PDF 用 pdf.js、Word 用 mammoth 在手机里解析） |
| 粘贴文本导入 | ✅ |
| 生成讲解 + 重点划分 | ✅（需要自己填 API Key） |
| 逐节编辑 / 单节重生成 | ✅ |
| 习题练习（出题 / 整理题目 / 自己出题 + 详解） | ✅ |
| PDF 识图导入（视觉模型逐页转写） | ✅ 需要视觉模型（qwen-vl-max / gpt-4o-mini 等） |
| 导出 | 仅 Markdown（下载到手机「下载」目录） |
| 网页抓取 / 登录抓取 / 附件下载 | ❌ 浏览器跨域限制，请在电脑版用 |
| Word / PPT / PDF 导出 | ❌ 请在电脑版导出 |

## 设置模型

第一次进去是「本地演示模型」（离线模板）。要真正的 AI 讲解：

1. 点右下角 **设置** → 新建/编辑供应商；
2. 常见填法：

| 供应商 | Base URL | 模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问（百炼兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 通义视觉（识图用） | 同上 | `qwen-vl-max` |

3. 填 API Key → 点「测试连接」→ 通过后保存并设为当前。

## 数据存在哪

- 材料、讲解、题集都存在**手机浏览器本地**（IndexedDB），不上传任何服务器；
- API Key 也存在本地（手机版没有系统级加密，明文保存在浏览器存储里，共用设备时请留意）；
- 换浏览器或清空站点数据会丢，重要内容记得导出 Markdown。

## 和电脑版的关系

同一套界面与提示词。电脑版（`AI-Tutor-Assistant.exe`）能做手机版做不到的三件事：
网页抓取（含登录）、附件下载、Word/PPT/PDF 导出。
